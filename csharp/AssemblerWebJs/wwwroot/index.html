About This Application

This is a client-side JavaScript implementation of the Arshu Polyglot Web Assembler template engine, running entirely in your browser.

Features

  • Get Templates: Fetch and view template structures from the server
  • Merge: Process templates client-side using JavaScript engines
  • Navigation: Browse through different template scenarios

Template Engine Rules

  • Rule 1: PlaceHolder Markup - {{PlaceholderName}}
  • Rule 2: Slotted Markup - {{#SlotName}} with {{@HTMLPLACEHOLDER}}
  • Rule 3: Context PlaceHolder Markup - Context-based rendering
  • Rule 4: JSON Key Assembly - {{$JsonKey}}
  • Rule 5: JSON Array Assembly - {{@JsonArrayKey}}

How It Works

The application fetches template definitions from the server, then uses client-side JavaScript engines (EngineNormal and EnginePreProcess) to merge and render the templates directly in your browser.

For more information, visit the GitHub repository.
