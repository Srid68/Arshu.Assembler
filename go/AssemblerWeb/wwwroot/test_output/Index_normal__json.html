About This Application

This is a server-side implementation of the Arshu Polyglot Web Assembler template engine.

Features

  • Component-Based: Built using modular template components
  • Dual Engine: Compare Normal and PreProcess engine implementations
  • Real-Time: See merged results instantly

Template Engine Rules

  • Rule 1: PlaceHolder Markup - {{PlaceholderName}}
  • Rule 2: Slotted Markup - {{#SlotName}} with {{@HTMLPLACEHOLDER}}
  • Rule 3: Context PlaceHolder - Context-based rendering
  • Rule 4: JSON Key Assembly - {{$JsonKey}}
  • Rule 5: JSON Array Assembly - {{@ArrayKey}}
