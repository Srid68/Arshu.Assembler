Overview

Arshu Assembler is a polyglot declarative framework for app creation, inspired by abstractions from Mustache, React, and HTMX. This project is a multi-language implementation recreated using AI-assisted development in multiple programming languages.

This repository represents Phase 2 of a larger project to build a polyglot web framework.

Core Features

The framework implements a component-oriented architecture for composing markup and data.

Direct Composition

Directly compose markup with placeholder-based inclusion

Slotted Composition

Compose markup into numbered slots for reusable layouts

AppView Context

Compose markup based on view context for dynamic rendering

JSON Key Composition

Merge markup with JSON objects for data binding

JSON Array Composition

Render markup iteratively with JSON arrays

Dual Engines

Normal and PreProcess engines for different assembly strategies

Quick Start

C#

cd csharp\AssemblerTest
dotnet run .

# Run the web application
cd ..\AssemblerWeb
dotnet run .

Rust

cd rust\AssemblerTest
cargo run .

# Run the web application
cd ..\AssemblerWeb
cargo run .

Go

cd go/AssemblerTest
go run .

# Run the web application
cd ../AssemblerWeb
go run .

Node.js

cd node/AssemblerTest
npm install
node index.js

# Run the web application
cd ../AssemblerWeb
npm install
npm start

PHP

cd php/AssemblerTest
composer install
php index.php

# Run the web application
cd ../AssemblerWeb
composer install
php -S localhost:8001 index.php
